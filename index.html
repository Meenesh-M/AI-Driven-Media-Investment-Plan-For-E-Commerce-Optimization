👨‍💻 About This Project

This project is a web-based application developed to intelligently allocate marketing budgets across multiple ad platforms like Google, Meta, and Microsoft Ads. It uses historical ad performance data to calculate Return on Ad Spend (ROAS) and distribute the total budget accordingly.

The goal is to help marketers make data-driven decisions by identifying which platform delivers the best value for every dollar spent.

The frontend is built using HTML, CSS, and JavaScript, while the backend is powered by FastAPI and Python.
